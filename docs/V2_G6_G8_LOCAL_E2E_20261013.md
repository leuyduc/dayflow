## Reproducible isolated setup

The ordinary workstation does not expose `DATABASE_URL` or a permanent PostgreSQL service. The known G3 Windows development strategy is used instead: PostgreSQL 17 runs from the gitignored local-only sandbox `.artifacts/postgres-sandbox/`, bound to `127.0.0.1:55433`. The test wrapper generates random credentials and a dedicated `dayflow_test_*` database at runtime. It neither reads a production credential nor connects to Linux.

One-time local test dependency (ignored, outside the production package graph):

```sh
npm install --prefix .artifacts/postgres-sandbox embedded-postgres@17.10.0-beta.17 --ignore-scripts --no-audit --no-fund
```

Reproducible command from the repository root:

```sh
npm run build
npm run test:browser:g6g8:postgres:local
```

The npm command invokes `scripts/test-g6-g8-postgres-local.mjs`, which starts/stops the disposable PostgreSQL instance and executes `scripts/browser-g6-g8-e2e.mjs`. The browser script exercises real Chrome, Vite, Fastify, Drizzle and PostgreSQL; it does not use mocked API responses. It creates only fixture accounts and tasks in its disposable database. A 390px mobile month-view screenshot is written under ignored `.artifacts/g6-g8-mobile-month.png`.
